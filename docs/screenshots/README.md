# Screenshots

Placeholders referenced from the main `README.md` — drop the real PNGs/JPGs here
with these exact filenames and the README's images resolve automatically:

- `dashboard.png` — hero shot, the main dashboard/application list.
- `role-assessment.png` — a run's Vacancy Report (fit score, recommendation, reasoning).
- `workspace.png` — a run's full detail view (report + application package + trace).
- `drafting.png` — the cover letter / application-answer drafting view, with the
  per-piece regenerate control visible.
- `workbenches.png` — Admin → Workbenches (optional — only if you want to show off
  multi-workspace management).

This folder itself is tracked by git; the images are not excluded by `.gitignore`,
so add them normally with `git add`.
